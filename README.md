# wonderful launcher ✦ ｖａｐｏｒｗａｖｅ

アプリが**3Dのスフィア（球体）**に浮かぶ、レトロなヴェイパーウェイヴ風 Android ホームアプリです。

## できること

### スフィア
- アプリのアイコンが球体状に並び、**スワイプで回転**（離すと慣性で回り続け、しばらくすると自動回転）
- **タップで起動**（アイコンから広がる起動アニメーション付き）
- **長押しでメニュー**：スフィアから外す / フォルダに追加 / ドックに追加 / 非表示 / アプリ情報 / アンインストール
- **2本指ピンチ**で球体の拡大縮小
- 並べ方は「球体・リング・螺旋・銀河」の4種類
- アプリの追加・削除は、検索画面の「球体を編集」でタップするだけ

### 四隅のボタン（割り当ては設定で変更可）
| 位置 | 機能 |
|---|---|
| 右上 | **検索**：アプリを検索（ひらがな/カタカナ・全角/半角を区別しない）。見つからなければWEB検索 |
| 右下 | **ウィジェット**：Androidのウィジェットや内蔵ウィジェット（レトロ時計・バッテリー・メモ）を自由に配置。縦にスクロール、「配置を編集」でドラッグ移動・サイズ変更 |
| 左上 | **最近使ったアプリ**：タップで起動。ランチャーの履歴か、端末全体の使用履歴から表示 |
| 左下 | **フォルダ**：フォルダを作って名前と色を決め、アプリを入れてそこから起動 |

設定は**何もない所を長押し**で開きます（ジェスチャー設定で変更可）。

### ジェスチャー（すべて割り当て変更可）
ダブルタップ / 長押し / 上部を下・左・右にスワイプ / 下部を上にスワイプ / 2本指で上・下にスワイプ / ホーム画面でホームボタン / 時計タップ。
割り当てられる動作：各パネル、通知、クイック設定、アプリ起動、カメラ、アシスタント、ライト、おやすみモード、
画面ロック・スクリーンショット・電源メニュー・タスク一覧（ユーザー補助が必要）、球体のスピン/リセット/シャッフル など。

### 権限（設定 → 権限、すべて任意）
| 権限 | できるようになること |
|---|---|
| 通知へのアクセス | アイコンに通知件数のバッジ（通知の内容は読みません） |
| ユーザー補助 | ジェスチャーで画面ロック・スクショ・電源メニュー・タスク一覧 |
| 使用状況へのアクセス | 「最近」に端末全体の使用履歴 |
| おやすみモードへのアクセス | ジェスチャーでおやすみモード切替 |

### バックアップの互換性
古いバージョンで書き出したバックアップもそのまま読み込めます（保存形式のバージョン番号＋自動マイグレーション）。
一部が壊れたバックアップでも、読める部分は復元します。互換性は `app/src/test` の自動テストで毎回確認しています。

### デザイン
- 夕焼け空・縞模様の太陽・山・流れるパースグリッドのアニメーション壁紙
- Windows 95 風ウィンドウ、ネオン発光文字、色収差（VHS風）、CRT走査線・ビネット
- パネルはボタンの位置から飛び出す「ズーム」など4種類のアニメーション
- カラーテーマ6種（Vaporwave / Synthwave / Outrun / Miami / Seapunk / Mac Plus）

### 壁紙
動く背景：ヴェイパー風景 / **水中**（光の筋・泡・魚・海藻）/ **迷路**（自動で生成して自動で解く）/ **グリッチ** /
デジタル雨 / ワープ / ラバランプ / オーロラ / ライフゲーム / グラデーション。
ほかに OSの壁紙 / ギャラリーの画像 / 単色。
どの壁紙にも細かい設定があります（例：迷路は作り方2種・解き方4種・速さ・壁の太さ、
**ライフゲーム**はルール13種・始まり方6種・セルの形と色・残光・人口グラフ・**タップでセルを置ける** など）。
暗さ・ぼかしの調整や、選んだ画像をOSの壁紙にも設定できます。

### エフェクト（設定 → エフェクト）
- **ゴム**：アイコンがバネのように遅れてついてきて、伸び縮みする（柔らかさ・弾み・伸び縮み・遅れの最大を調整可。
  速く回した時は揺れを抑えるので、アイコンが潰れたり裏返ったりしません）
- **グロー・残像**：光の強さ/大きさ/明滅/虹色、残像の長さ/間隔/見た目（アイコン・ネオン光・光の線）
- **タップの動き**：ぷるん / バウンド / スピン、タップで火花
- **ぼかし**：奥のアイコンをぼかす（被写界深度）、パネル表示中に背景をぼかす（Android 12+）
- **アイコンの動き**：ふわふわ浮遊、残像、虹色グロー
- **画面全体**：フィルムグレイン、VHSトラッキング、ランダムグリッチ、走査線、ビネット
- プリセット（控えめ / ぷるぷる / VHS / 全部盛り）

### 時計の位置・ジェスチャーでウィジェット
- 時計の位置に「時計 / ウィジェット / 時計＋ウィジェット / なし」を選べます（設定 → 時計）
- ジェスチャーの動作「ウィジェット表示」で、好きなウィジェットをポップアップで呼び出せます（設定 → ジェスチャー）
- どちらも内蔵ウィジェット・Android のウィジェットのどれでも選べます

### 充電アニメーション
電源をつなぐと、ネオン電池 / リング / 稲妻 / 液体 のアニメーションで残量をカウントアップ表示（設定 → 充電）。

### 軽量化（設定 → 軽量化）
- 軽量モード：重い演出をまとめて止める（OFF に戻すと元通り）
- 最大フレームレート（制限なし / 60 / 45 / 30 / 20 / 15fps）
- 操作しない時に動く壁紙・自動回転を止める

### システムモニター系ウィジェット
メモリ / CPU（コアごとの周波数）/ 温度（電池・CPU・発熱状態）/ ストレージ / 通信速度 / システムモニター（まとめ表示）/ メモリ解放ボタン。
※ Android 8 以降は一般アプリが CPU 使用率を読めないため、CPU は動作周波数から負荷の目安を表示します。

### 設定（18カテゴリ）
球体・ボタン・見た目・エフェクト・壁紙・時計・検索・履歴・フォルダ/ドック・ウィジェット・ジェスチャー・権限・アプリ管理・システム・バックアップ・情報。
球体の大きさ、遠近感、回転速度や慣性、アイコンの形やグロー、時計のスタイル、ダブルタップ/長押しの動作、
ステータスバーの非表示、設定のJSON書き出し/読み込みなど、ほぼすべてを調整できます。

## ビルド方法

### GitHub Actions（PC不要）
リポジトリに push すると `.github/workflows/build.yml` が APK をビルドします。
Actions タブの実行結果から **wonderful-launcher-debug** をダウンロードし、中の APK をスマホにインストールしてください。

### Android Studio
1. このリポジトリを開く
2. `app` を実行（または `./gradlew assembleDebug`）

### 使い始める
1. APK をインストールして起動
2. ホームボタンを押して「wonderful launcher」を選ぶ（または 設定 → システム →「デフォルトのホームに設定」）

## 動作環境
- Android 8.0（API 26）以上
- Kotlin / Jetpack Compose

## 構成
```
app/src/main/java/com/wonderful/launcher/
├── MainActivity.kt          ホーム画面のActivity
├── data/                    設定・保存・アプリ一覧・OS連携
└── ui/
    ├── HomeScreen.kt        画面全体の組み立て・パネルのアニメーション
    ├── LauncherViewModel.kt 状態と操作
    ├── sphere/              3D球体の計算(SphereEngine)と描画・ジェスチャー(SphereView)
    ├── panels/              検索・最近・フォルダ・アプリメニュー
    ├── settings/            設定画面
    ├── wallpaper/           ヴェイパー壁紙・CRTエフェクト
    ├── components/          レトロUI部品・時計・四隅ボタン・ドック
    └── theme/               カラーテーマ
```
