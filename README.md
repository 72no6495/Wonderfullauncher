## ⬇ ダウンロード

1. [**Releases**](https://github.com/72no6495/Wonderfullauncher/releases/latest) から `wonderful-launcher-vX.Y.Z.apk` をダウンロード
2. スマホで APK を開いてインストール（「提供元不明のアプリ」の許可を求められたら許可してください）
3. ホームボタンを押して **wonderful launcher** を選び、「常に」をタップ

> 設定 → システム →「デフォルトのホームに設定」からも切り替えられます。
> 元のホームに戻したい時は、Android の 設定 → アプリ → デフォルトのアプリ → ホームアプリ で変更してください。

**動作環境**: Android 8.0（API 26）以上

## ✦ 特徴

### 🌐 アプリの球体
- アプリのアイコンが球体に並び、**スワイプで回転**します。指を離しても慣性で回り続け、しばらくすると自動で回り出します
- **タップで起動**、**長押しでメニュー**（球体から外す / フォルダ・ドックに追加 / 非表示 / アプリ情報 / アンインストール）
- **2本指ピンチ**で拡大・縮小
- 並べ方は 球体・リング・螺旋・銀河 の4種類
- 初回起動時は、電話・ブラウザ・カメラなどの定番アプリと最近入れたアプリから **おすすめの24個** だけを並べます。アプリの出し入れは「球体を編集」でタップするだけです

### 🔲 四隅のボタン
| 位置 | 機能（割り当ては変更できます） |
|---|---|
| ↖ 左上 | **最近使ったアプリ** |
| ↗ 右上 | **検索**：ひらがな/カタカナ、全角/半角を区別しません。見つからなければ Web 検索 |
| ↙ 左下 | **フォルダ**：名前と色を決めて、アプリをまとめられます |
| ↘ 右下 | **ウィジェット**：Android のウィジェットと内蔵ウィジェットを自由に配置。縦にスクロールできます |

設定は **何もない所を長押し** で開きます。

### 🌅 動く壁紙
ヴェイパー風景 / 水中 / 迷路（自動で作って自動で解く）/ グリッチ / デジタル雨 / ワープ / ラバランプ / オーロラ / ライフゲーム / グラデーション。
ほかに OS の壁紙、ギャラリーの画像、単色も使えます。どの壁紙にも細かい設定があり、ライフゲームはルール13種・タップでセルを置く・人口グラフなどに対応しています。

### ✨ エフェクト
- **ゴム**：アイコンがビヨンビヨンと遅れてついてくる
- **グロー・残像**、**タップの動き**（ぷるん / バウンド / スピン / 火花）
- **ぼかし**（被写界深度・パネル背景、Android 12+）
- フィルムグレイン、VHS トラッキング、グリッチ、走査線、ビネット
- プリセット：控えめ / ぷるぷる / VHS / 全部盛り

### ⚡ 充電アニメーション
電源をつなぐと、ネオン電池 / リング / 稲妻 / 液体 のアニメーションで残量を表示します。
衝撃波から始まり、セルが1マスずつ点灯して電撃が走ります。対応端末では電流・電圧・温度も表示します。

### 🧩 内蔵ウィジェット
レトロ時計 / バッテリー / メモ / メモリ / CPU / 温度 / ストレージ / 通信速度 / システムモニター / メモリ解放ボタン。
**時計の位置に好きなウィジェットを置く**ことや、**ジェスチャーでウィジェットを呼び出す**こともできます。

### 👆 ジェスチャー
ダブルタップ / 長押し / 上下左右のスワイプ / 2本指スワイプ / ホームボタン / 時計タップ に、
パネル・通知・クイック設定・アプリ起動・カメラ・ライト・おやすみモード・画面ロック・スクリーンショット・ウィジェット表示 などを割り当てられます。

### 🎨 テーマ
Vaporwave / Synthwave / Outrun / Miami / Seapunk / Mac Plus の6色。Windows 95 風ウィンドウ、ネオン文字、色収差、CRT 走査線などの演出があります。

### ⚙ 設定
球体・ボタン・見た目・エフェクト・壁紙・時計・検索・履歴・フォルダ/ドック・ウィジェット・ジェスチャー・充電・軽量化・権限・アプリ管理・システム・バックアップ など。ほぼすべての見た目と動きを調整できます。

## 🔋 電池・発熱について

演出が多いアプリなので、初期設定でも次のように負荷を抑えています。

- 画面が止まっている時は描画を休みます（操作しない時の自動回転・動く壁紙も止まります）
- 最大フレームレートは 60fps（設定 → 軽量化 で 15〜60fps / 制限なし を選べます）

さらに軽くしたい時は、設定 → 軽量化 の **「おすすめの省エネ設定にする」** か **軽量モード** を使ってください。

---

## 🔐 権限とプライバシー

権限はすべて **任意** です。付与しなくても基本機能は使えます（設定 → 権限 から付与できます）。

| 権限 | できるようになること |
|---|---|
| 通知へのアクセス | アイコンに通知件数のバッジを表示（**通知の内容は読みません**） |
| ユーザー補助 | ジェスチャーで画面ロック・スクリーンショット・電源メニュー・タスク一覧 |
| 使用状況へのアクセス | 「最近」に端末全体の使用履歴を表示 |
| おやすみモードへのアクセス | ジェスチャーでおやすみモードを切り替え |

- インターネット権限を使わないため、データを外部に送信することはありません
- 設定やレイアウトは端末の中にだけ保存されます

---

## 💾 バックアップ

設定 → バックアップ から、設定・球体・フォルダ・ウィジェット配置を JSON ファイルに書き出し / 読み込みできます。
**古いバージョンで書き出したバックアップも、新しいバージョンでそのまま読み込めます。** 一部が壊れたファイルでも、読める部分は復元します。

## ❓ よくある質問

<details>
<summary>CPU の使用率が表示されず、周波数になっている</summary>

Android 8 以降は一般のアプリが CPU 使用率を読めないため、各コアの動作周波数から負荷の目安を出しています。
</details>

<details>
<summary>新しいバージョンを上書きインストールできない</summary>

署名の鍵が違う APK どうしは上書きできません。今のアプリの設定をバックアップしてからアンインストールし、入れ直してください。
</details>

<details>
<summary>画面ロックなどのジェスチャーが動かない</summary>

設定 → 権限 から「ユーザー補助」を有効にしてください。
</details>

## 🛠 ソースからビルド

```bash
git clone https://github.com/72no6495/Wonderfullauncher.git
cd Wonderfullauncher
./gradlew assembleDebug        # app/build/outputs/apk/debug/
./gradlew testDebugUnitTest    # バックアップ互換性のテスト
```

JDK 17 と Android SDK（API 35）が必要です。Android Studio で開いて `app` を実行することもできます。

### リリースの作り方（メンテナー向け）

`v1.2.3` のようなタグを push するか、Actions の Release ワークフローを手動実行（タグ名を入力）すると、[Release ワークフロー](.github/workflows/release.yml) がテスト・ビルドをして GitHub Releases に APK を公開します。
リリースノートは `.github/release-notes.md` に書きます。

署名には次のリポジトリ Secrets を使います（未設定なら debug 鍵で署名されます）。

| Secret | 内容 |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | keystore ファイルを base64 にしたもの |
| `SIGNING_STORE_PASSWORD` | keystore のパスワード |
| `SIGNING_KEY_ALIAS` | 鍵のエイリアス |
| `SIGNING_KEY_PASSWORD` | 鍵のパスワード |

```bash
keytool -genkeypair -v -keystore release.jks -alias wonderful -keyalg RSA -keysize 4096 -validity 36500
base64 -w0 release.jks   # → SIGNING_KEYSTORE_BASE64 に貼る
```

### 構成

```
app/src/main/java/com/wonderful/launcher/
├── MainActivity.kt          ホーム画面の Activity
├── data/                    設定・保存・マイグレーション・アプリ一覧・OS 連携・システムモニター
├── system/                  通知バッジ・ユーザー補助サービス
└── ui/
    ├── HomeScreen.kt        画面全体の組み立て・パネルのアニメーション
    ├── LauncherViewModel.kt 状態と操作
    ├── sphere/              3D 球体の計算と描画・ジェスチャー
    ├── panels/              検索・最近・フォルダ・ウィジェット・アプリメニュー
    ├── settings/            設定画面
    ├── wallpaper/           動く壁紙・画面エフェクト・充電アニメーション
    ├── components/          レトロ UI 部品・時計・四隅ボタン・ドック・ウィジェット
    └── theme/               カラーテーマ・フレームレート制御
```
